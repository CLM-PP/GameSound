# GameSound

Optimisation audio gratuite pour les jeux compétitifs : entendre les pas, les soins et les rechargements avant les autres.

## Installation

1. Télécharge **GameSound-Setup.exe** dans la [dernière version](https://github.com/CLM-PP/GameSound/releases/latest).
2. Lance-le. Si Windows affiche « Windows a protégé votre PC » : **Informations complémentaires** → **Exécuter quand même**.
3. Si la fenêtre « Device Selector » s'ouvre, **coche ton casque** puis OK.
4. Dans GameSound : **Autre casque…** pour choisir ton casque, le reste se règle tout seul.

Les mises à jour s'installent ensuite automatiquement.

## Ce que ça fait

- Correction de ton casque (base AutoEQ, plus de 8000 modèles)
- Profils par jeu (Apex Legends, Call of Duty, Battlefield 6, Valorant, CS2, Fortnite), détectés automatiquement
- Réglages précis : soins, rechargements, pas lourds, voix, détails lointains, explosions
- Égaliseur de volume qui remonte les sons faibles
- Raccourci en jeu **Ctrl + Maj + F12** pour activer / désactiver

Basé sur [Equalizer APO](https://sourceforge.net/projects/equalizerapo/) et [LoudMax](https://loudmax.blogspot.com/), téléchargés depuis leurs sites officiels pendant l'installation.
