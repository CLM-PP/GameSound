# OptiSonGnon

Optimisation audio gratuite pour les jeux compétitifs : entendre les pas, les soins et les rechargements avant les autres.
(Anciennement « GameSound ».)

## Installation

1. Télécharge **OptiSonGnon-Setup.exe** dans la [dernière version](https://github.com/CLM-PP/GameSound/releases/latest).
2. Lance-le. Si Windows affiche « Windows a protégé votre PC » : **Informations complémentaires** → **Exécuter quand même**.
3. Si la fenêtre « Device Selector » s'ouvre, **coche ton casque** puis OK.
4. L'assistant de démarrage s'occupe du reste (casque, test du son, jeu principal).

Les mises à jour s'installent ensuite automatiquement.

## Ce que ça fait

- Correction de ton casque (base AutoEQ, plus de 8000 modèles), détectée automatiquement
- 14 profils de jeux (Apex Legends, Valorant, Call of Duty, Fortnite, CS2, Rainbow Six Siege, PUBG, Overwatch 2, The Finals, Marvel Rivals, Escape from Tarkov…), détectés au lancement du jeu
- Égaliseur du jeu avec analyseur en direct et « Capturer le dernier son »
- Préréglages par jeu et codes de partage entre potes
- Mode Écoute sur la touche ou le bouton de souris de ton choix
- Raccourcis en jeu : **Ctrl + Maj + F12** (activer / désactiver), **Ctrl + Maj + F11** (réglage suivant)

Basé sur [Equalizer APO](https://sourceforge.net/projects/equalizerapo/) et [LoudMax](https://loudmax.blogspot.com/), téléchargés depuis leurs sites officiels pendant l'installation.
